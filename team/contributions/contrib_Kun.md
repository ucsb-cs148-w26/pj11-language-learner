## Code Contributions
### Backend
* Developed the [Profile backend API](https://github.com/ucsb-cs148-w26/pj11-language-learner/pull/64) and designed the **database schema for user profiles**.
* Refactored the system to **separate frontend and backend API calls** to address security concerns for  
  [profile](https://github.com/ucsb-cs148-w26/pj11-language-learner/pull/154)<br>
  [dashboard](https://github.com/ucsb-cs148-w26/pj11-language-learner/pull/162)<br>
  [chats](https://github.com/ucsb-cs148-w26/pj11-language-learner/pull/163)
* Added support for [multiple target languages](https://github.com/ucsb-cs148-w26/pj11-language-learner/pull/141) and refactored related backend code to enable multilingual functionality.
* Led the development of the [phonetic pronunciation feature](https://github.com/ucsb-cs148-w26/pj11-language-learner/pull/177), which:
  * Fetches message IDs
  * Detects message language
  * Generates phonetic pronunciation
  * Added a **button bubble component next to message bubbles** to trigger pronunciation.

### Infrastructure
* Developed a [**script for automatically fetching logs from failed deployments**](https://github.com/ucsb-cs148-w26/pj11-language-learner/issues?q=is%3Aissue%20author%3A%40me).
* Not reflected through github. Implemented a **bypass to vercel** to allow team members to view [preview pages](https://172.236.253.25) as long as your token and version info are carried in cookies, even though theoretically only the owner can view due to free plan. 
* Fixed **Row-Level Security (RLS) policies** to resolve database security vulnerabilities.
