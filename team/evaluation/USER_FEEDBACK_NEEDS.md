# User Feedback Needs
Wednesday, 2/18/2026

1. User Satisfaction w/ Messaging Feature - We want feedback on how easy and effective the messaging feature is for starting conversations between users. This will be measured using satisfaction ratings (1–5 scale), task success rate for sending a first message, and perceived ease of use. These metrics help determine whether users can communicate smoothly after finding a partner.

2. Effectiveness of Finding Suitable Language Matches - We want to evaluate how well users can describe their language goals and whether the platform provides matches aligned with those goals. This will be measured through ratings of profile clarity, match relevance (1–5 scale), and the percentage of users who choose to message a suggested match. These results indicate how successfully the system connects learners with compatible partners.
   
3. User Preference between Product Name and Logo Options - We want feedback on which product name and logo best communicates the purpose of the platform and creates a positive first impression. We would measure user preference for each product name and logo by recording which design users select as their preferred option, asking them to rate how likely they would be to use a platform with that branding (1–5 scale), and evaluating how accurately users can identify the platform’s purpose based only on the design.
